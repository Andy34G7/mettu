Welcome to the **mettu** documentation. `mettu` is a modern, fast static site generator combining Python for content compilation with Vite, Tailwind CSS, and DaisyUI for asset bundling and developer experience.

## Core Features

- **Blazing Fast**: Incremental builds, persistent parsing caches, and instant Vite hot-module reloading.
- **Component Themes**: Powered by Tailwind CSS and DaisyUI plugins with runtime theme switching.
- **Modern Markdown**: Syntax highlighting via Pygments, automatic Table of Contents, responsive images with WebP/AVIF generation.
- **Full-Text Client Search**: Zero-dependency instantaneous docs search using generated search indexes.
